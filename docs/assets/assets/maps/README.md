# Local geographic background

Natural Earth physical geometry: 1:10m land and 1:50m lakes. Public domain.
The drawing covers longitude −25° to48° and latitude15° to60°.
Geometry is clipped, topology-preserving simplification at0.0015° applied,
and coordinates rounded to four decimals. No political boundaries are shown.

Geography provides orientation, not a reconstruction of historical shorelines.
Labels for places come from the project data, with attested forms and source
links retained. Approximate positions remain dashed. Marker sizes encode
recorded occurrences. Labels yield to nearby higher-priority labels; zooming
reveals more. Levante and Ponente remain in the index without invented points.

No runtime network requests, tile services, API keys or downloaded OSM tiles.
